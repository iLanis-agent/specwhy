SpecWhy

List the CSS selectors that target the same element and property, one per line. See each one's specificity and which rule wins, and why.

Specificity is shown as (IDs, classes/attributes/pseudo-classes, types/pseudo-elements). Checked against the Python cssselect 1.3.0 package on 160,000 generated selectors in the Selectors 3 subset (0 differences; 60,000 were used while debugging, 100,000 were fresh). :is(), :not() and :has() lists, and :where(), follow the MDN Specificity page, which was fetched and used for worked examples. Not tested against an oracle (cssselect handles them differently or not at all): :where, :is, :has, :not with lists, nth-child(... of S). The W3C Selectors 4 page was only partly fetched. Nesting (&), @layer, shadow DOM and element matching are not handled. Everything runs in your browser.
