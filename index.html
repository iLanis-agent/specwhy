What it does

  • Scores each selector as (IDs, classes, types) and ranks competing rules: !important, inline style, specificity, then source order.
  • Handles selector lists, :is(), :not(), :has(), :where() (zero), pseudo-elements and attribute selectors.
  • Names the reason a rule wins, and points at selectors that are not valid.

How far to trust it

  • On 160,000 generated selectors it agrees with the Python cssselect package (Selectors 3 subset). Modern pseudo-classes (:is, :not lists, :has, :where) follow the MDN Specificity page, which was fetched, and are checked on its examples only. @layer, nesting and shadow DOM are not covered.
